## Deskripsi Proyek
Aplikasi manajemen data mahasiswa sederhana menggunakan PHP Native dan MySQL dengan tema Grey Edition.

### Fitur Utama:
- CRUD:Tambah, Tampil, Edit, dan Hapus data mahasiswa.
- Upload Foto:Mendukung unggah foto profil (Maksimal 2MB).
- Validasi:Validasi input sisi klien menggunakan JavaScript.
- Database:Menggunakan MySQL dengan ekstensi MySQLi.

## Cara Instalasi
1. Clone repository ini.
2. Import file `kampus_db.sql` ke phpMyAdmin.
3. Pastikan folder `uploads` memiliki izin akses tulis (write access).
